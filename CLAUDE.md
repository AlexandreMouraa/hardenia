# Hardenia: instruções para o Claude Code

**Leia antes de qualquer mudança:** @AGENTS.md

O que não pode faltar, mesmo que o resto passe:

- Todo branch novo sai da **`homologacao`**, e todo PR vai para a **`homologacao`**
  (`gh pr create --base homologacao`). Nunca para a `main`.
- Nunca faça push direto na `main` nem na `homologacao`, e nunca faça merge. Quem faz o merge é o Alexandre.
- Uma issue, um branch, um PR.
